#**Администрирование Linux**

Данный репозиторий будет содержать команды, скриншоты по администрированию Linux с практики, которые я выпляю.
В практике задейстованы два Linux OS. Первая это Debian, а вторая - CentOs.
Про каждое семейсво будет отдельное знакомство, различия, а также скриншоты с практики, с пояснениями, команды, установки пакетов и другой полезной информации.
