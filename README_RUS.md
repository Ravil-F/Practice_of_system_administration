# **Администрирование Linux**

Данный репозиторий будет содержать команды, скриншоты по администрированию Linux с практики, которые я выпляю.
В практике задейстованы два Linux семейства. Первая это Debian, а вторая - Red Hat.
Про каждое семейсво будет отдельное знакомство, различия, а также скриншоты с практики, с пояснениями, команды, установки пакетов и другой полезной информации.


## **Debian**

В этой папке будут распологаться *README_DEBIAN_RU.md* файл, где будет описана история, особенности семейсва *Debian*.
В каталоге так же будут папки, в которых будут оформлены файлы типа *Markdown*. В них будут описания команд, вопросы, а также решения к ним со скриншотами.


## **CentOs**

В этой папке будут распологаться *README_CentOs_RU.md* файл, где будет описана история, особенности семейсва *Red Hat*.
В каталоге так же будут папки, в которых будут оформлены файлы типа *Markdown*. В них будут описания команд, вопросы, а также решения к ним со скриншотами.
