# Создание пользователя в Linux

В Linux создавать пользователей может только суперпользователь (root), поэтому используем ```sudo```

## Что такое пользователи в Linux и зачем они нужны?
**Linux** — многопользовательская система. Пользователь — это учетная запись, которая идентифицируется числом (UID — User ID).<br>
Зачем это нужно:

1. Безопасность: Ограничение прав. Обычный пользователь не может удалить системные файлы или прочитать чужие данные.

2. Разграничение доступа: У каждого пользователя свои файлы, настройки и история команд.

3. Аудит: Всегда видно, кто и что сделал в системе.

Типы пользователей:

1. Root (UID 0): Суперпользователь, может всё.

2. Системные (UID 1–999): Служебные учетки для сервисов (например, для веб-сервера www-data или для демона sshd). Им нельзя логиниться в систему.

3. Обычные (UID 1000+): Ты, твой пользователь student и другие реальные люди.

## Что такое группы?
Пользователи объединяются в группы (идентификатор GID), чтобы было удобнее управлять правами на файлы.

1. Основная группа: Создается автоматически вместе с пользователем (обычно совпадает с его именем). Файлы, которые создает пользователь, получают эту группу.

2. Дополнительные группы: Ты добавляешь пользователя в группу adm, чтобы он получил права этой группы.

Что дает группа adm? В Debian/Ubuntu пользователи этой группы могут читать системные логи в /var/log/ (например, syslog), не имея полных прав root. Это нужно системным администраторам.

## Основные команды для работы с пользователями.
1. Создание пользователя и пароля:
1.1. ```sudo useradd -m -s /bin/bash <user name>``` - создание пользователя. Флаг ```-m``` создает домашнюю директорию ```/home/<user name>```, а ```-s``` задает оболочку bash. Классическая, кроссплатформенная, есть везде.
1.2.```sudo adduser username``` - интерактивная, удобнее в Debian/Ubuntu, сама создаст папку и спросит пароль.
1.3. ```sudo passwd <user name>``` - задаем пароль новому пользователю. Вводим пароль дважды, при вводе символы не отображаются - это нормально.
<br>
2. Изменить пользователя (модифицировать):
```sudo usermod [flag] <user name>```
- -aG groupname — добавить в группу (не удаляя из других).
- -s /bin/bash — сменить оболочку.
- -L / -U — заблокировать / разблокировать аккаунт.
